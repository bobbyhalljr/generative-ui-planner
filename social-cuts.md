# LinkedIn

CopilotKit released Open Intelligent UI on October 9: agent answers can become text, components, or interactive interfaces.

The decision I care about happens before rendering: does the data deserve the chosen view?

I built a tiny TypeScript planner. Complete, regularly spaced data gets a line-chart plan. A missing measurement gets a table plan that preserves null.

Zero is data. Missing is not zero.

18 local checks cover missing values, mixed units, impossible dates, ordering, nonfinite numbers, and more. No API key.

Honest limits: this returns a component plan. It does not run CopilotKit, render charts, or sandbox generated code. The rules are a conservative local policy.
